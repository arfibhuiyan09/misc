About the Hyper-Fractal Engine

This is an ultra-advanced real-time WebGL application rendering non-Euclidean geometries, recursive Mandelbulb/Julia fractal universes, gravitational lensing, and volumetric audio-reactive neon corridors entirely inside a GPU fragment shader.

1. Audio-Reactive Raymarching

Using the Web Audio API analyzer node, real-time frequency spectrum data (bass, mid, highs) is piped directly into the GLSL uniforms to dynamically warp fractal power, twist space, and pulsate neon glow intensities in sync with the beat.

2. Non-Euclidean & Gravitational Lensing

Rays are bent in curved spacetime fields using custom distance estimators and non-linear ray transformations. This creates infinite corridors and bending light around hyper-dense gravitational singularities.

3. Interactive Controls

Click and drag anywhere on the screen to orbit the camera through the 3D fractal multiverse. Use the control deck to switch dimension archetypes, tune spectra palettes, or toggle between microphone input and synthetic audio streams.
